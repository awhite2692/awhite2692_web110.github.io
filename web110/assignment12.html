In this assignment, I learned how JavaScript can dynamically display information on a webpage. I used JavaScript to insert my name into a heading and display the current date and time in a paragraph. I also learned that JavaScript retrieves the date and time from the computer's system clock and formats it for display based on the computer's regional settings. These techniques can be applied to my own web projects and professional environments, including online training materials and virtual instructor-led training (VILT), where displaying current or changing information can make content more useful and interactive.
